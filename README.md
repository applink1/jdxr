# JDXR
fallback pages for the Profile and Post Sharing
## Real examples with actual IDs:
- https://applink1.github.io/jdxr/profile?userRef=abc123
- https://applink1.github.io/jdxr/post?postRef=xyz789

## These will internally trigger:
- jdxr://jdxr.com/userProfile?userRef=users/abc123
- jdxr://jdxr.com/postsDetailsView?postRef=posts/xyz789
